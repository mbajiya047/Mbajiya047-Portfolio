# 🎮 MOHIT — TRAINER & DEVELOPER PORTFOLIO [SYSTEM GBA]

A retro Pokémon Game Boy Advance (GBA) themed interactive portfolio built for Mohit (B.Tech CSE Student & Full-Stack Developer).

![Version](https://img.shields.io/badge/version-2.6-blue.svg)
![Theme](https://img.shields.io/badge/theme-Pokemon%20GBA-gold.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

---

## ✨ Features

- 🎮 **Retro GBA HUD**: 8-bit sound effects, authentic CRT scanlines, and animated canvas background.
- 🛡️ **Trainer Access Gate**: Interactive visitor registration system.
- ⚡ **Battle System & Quests**: Interactive developer skills, project showcases, and achievements.
- 📜 **Certificate Vault**: Interactive preview modals for certifications and achievements.
- 📄 **Resume Integration**: Integrated CV viewer and download support.
- 🚀 **Zero External Frameworks**: Pure HTML5, CSS3, and modern Vanilla JavaScript with blazing fast load times.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3** (Vanilla CSS, Custom Properties, Glassmorphism, Retro CRT styling)
- **JavaScript** (ES6+, Web Audio API Synthesizer, Dynamic DOM Rendering)
- **Deployment**: Vercel

## 📦 Local Development

1. Clone or download the repository:
   ```bash
   git clone https://github.com/mbajiya047/Mbajiya047-Portfolio.git
   cd portfolio
   ```

2. Open `index.html` directly in your browser or run a local static server:
   ```bash
   npx serve .
   ```
